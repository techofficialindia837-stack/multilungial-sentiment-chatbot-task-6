# 🌍 Multilingual Sentiment-Aware Chatbot

## 📌 Project Overview

This project is a **Multilingual Sentiment-Aware Chatbot** that can:

* Detect the user's language automatically
* Understand user sentiment (positive/negative)
* Respond in the same language with an appropriate tone

The chatbot uses Natural Language Processing (NLP) and translation techniques to deliver intelligent and user-friendly responses.

---

## 🚀 Features

* 🌐 Automatic Language Detection
* 🔄 Multilingual Support (English, Hindi, Spanish, French)
* 🧠 Sentiment Analysis (Positive / Negative)
* 🤖 Emotion-aware Responses
* ⚡ Fast and lightweight
* 🌍 Seamless language switching

---

## 🛠️ Technologies Used

* Python
* Streamlit
* Transformers (Hugging Face)
* LangDetect
* Deep Translator
* NLP Techniques

## ⚙️ Installation & Setup

### 1️⃣ Clone Repository

```
git clone <your-repo-link>

```

### 2️⃣ Install Dependencies

```
pip install -r requirements.txt
```

### 3️⃣ Run Application

```
streamlit run app.py
```

## 🌐 Usage

1. Enter your message in any supported language
2. Click **Send**
3. The chatbot will:

   * Detect language
   * Analyze sentiment
   * Respond in the same language
